# Venture Craft

**Play in your browser: https://slickmacher.github.io/venture-craft-play/**

Start any of 361 businesses across 18 industries, choose your founders, and make one set of decisions every quarter for at least five years. Failure odds are tuned to U.S. Bureau of Labor Statistics survival rates, so an ordinary player faces the same odds a real founder does.

This is an early prototype. When a game ends, three quick questions ask what you thought.

This repository holds only the playable build.
